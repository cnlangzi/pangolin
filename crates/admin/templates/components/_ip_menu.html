{# components/_ip_menu.html — the IP-lookup menu of the rate-limit tables. #} {# #} {# One page-level panel, included by `layouts/base.html` right after the #} {# content block. It is a **single** element on purpose: #} {# #} {# - the tables live in regions that htmx replaces wholesale every two #} {# seconds (`hx-swap="innerHTML"`), so a per-row panel would destroy #} {# itself in the middle of the interaction; #} {# - the panel has to live **outside** every swapped region for the #} {# same reason — it is a child of ``, not of a table. #} {# #} {# The entries carry the URL of their site with an `{ip}` placeholder. The #} {# client-side code replaces the placeholder with the address of the row #} {# the menu was opened from and sets the `href` — the panel ships without #} {# a `href`, so an entry can never point at a literal `{ip}`. #} {# #} {# The Tailwind classes below must appear literally here: the Tailwind #} {# content glob does not scan `assets/app.js`, so a class that only #} {# appears there is purged from the stylesheet and the menu ships #} {# unstyled. The panel is positioned with absolute coordinates computed #} {# by the script, so it is never `fixed` — a fixed panel would stay #} {# behind when the page scrolls. #}
