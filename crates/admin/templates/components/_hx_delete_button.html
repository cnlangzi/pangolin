{# components/_hx_delete_button.html — unified HTMX delete button macro. #} {# #} {# This file is NOT meant to be `{% include %}`-ed directly. Instead, #} {# `{% import "components/_hx_delete_button.html" as hx %}` it once per #} {# template and call `{{ hx::btn(url=..., confirm=..., variant=..., #} {# target=...) }}` wherever a delete button is needed. #} {# #} {# Why this exists (issue #48): #} {# Before issue #48, every admin table had its own legacy POST wrapper #} {# around the delete button with a hidden CSRF input. The result was #} {# inconsistent UX (full page reload vs row swap) and a dual CSRF injection#} {# path. This macro unifies on HTMX `hx-delete` so the row gets swapped #} {# out in place (`hx-swap="delete"`) and the CSRF token rides in the #} {# request body via `hx-vals`, matching the `__CSRF__` substitution that #} {# `render_with_csrf` already performs. #} {# #} {# Parameters: #} {# url (required) — DELETE endpoint, e.g. "/api/sites/foo" #} {# confirm (required) — hx-confirm message, e.g. "Delete site foo?" #} {# variant (optional) — "icon" (default; p-1.5 trash icon, desktop row) #} {# or "text" (full-width red "Delete" button, mobile)#} {# target (optional) — hx-target selector. Defaults to "this" which #} {# only works when the button is not inside a row #} {# wrapper. Pass "closest tr" for table rows or #} {# "closest div" / specific ID for mobile cards. #} {# extra_class (optional) — additional Tailwind classes appended. #} {# #} {# The CSRF placeholder `__CSRF__` is replaced at render time by #} {# `render_with_assets_and_csrf`. See `lib.rs`. #} {# #} {# Example usage: #} {# {% import "components/_hx_delete_button.html" as hx %} #} {# … #} {# {{ hx::btn( #} {# url="/api/sites/foo", #} {# confirm="Delete site foo?", #} {# variant="icon", #} {# target="closest tr", #} {# ) }} #} {% macro btn(url, confirm, variant, target, extra_class) %} {% if variant == "text" %} {# ── Mobile / card variant — full-width red "Delete" button. ──────────── #} {% else %} {# ── Desktop / table variant — p-1.5 trash-icon button (default). ─────── #} {% endif %} {% endmacro btn %}
