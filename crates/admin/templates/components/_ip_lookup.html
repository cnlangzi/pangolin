{# components/_ip_lookup.html — the shared cells of the rate-limit tables. #} {# #} {# Two macros, imported by the templates that render a client-IP cell #} {# and a bot cell: #} {# #} {# {% import "components/_ip_lookup.html" as lookup %} #} {# {{ lookup::ip_cell(ip=row.ip) }} #} {# {{ lookup::bot_cell(name=row.bot_name, dash_class="text-slate-400") }} #} {# {{ lookup::badbot_cell(code=row.badbot_code, dash_class="…") }} #} {# #} {# Why a macro and not an `{% include %}`: an include takes a path only, #} {# so the two tables could not pass their own address and their own #} {# empty-dash colour. A macro takes parameters, so the markup — and #} {# with it the contract the client-side lookup in `assets/app.js` #} {# relies on — is defined once. #} {# #} {# Parameters: #} {# ip (required) — the client address of the row. #} {# name (required) — the registry id of the known bot, or None. #} {# dash_class (required) — the muted em dash of the table the cell #} {# belongs to. #} {# #} {# The Tailwind classes below must appear literally here: the Tailwind #} {# content glob does not scan `assets/app.js`, so a class that only #} {# appears there is purged from the stylesheet and the element ships #} {# unstyled. The client-side code only writes text into the placeholders #} {# and toggles their visibility. #} {# The client-IP cell: the address, the magnifier button that looks the #} {# address up, and the two lines the answer is rendered into. #} {% macro ip_cell(ip) %} {{ ip }}
{% endmacro ip_cell %} {# The bot cell: the registry id of the verified known bot as a blue #} {# chip — red, yellow and purple are taken by the 403 / 429 status #} {# badges (issue #134) — or a muted em dash for a client that is not a #} {# verified known bot. #} {% macro bot_cell(name, dash_class) %} {% if let Some(b) = name %} {{ b }} {% else %} — {% endif %} {% endmacro bot_cell %} {# The reputation-verdict cell (issue #141): what the IP reputation #} {# library said about the client — a badge whose colour is keyed off #} {# the verdict code — or a muted em dash for a client the library was #} {# never asked about (a verified known bot, a request without an #} {# authoritative client IP). #} {# #} {# The badge markup lives here, not in the two tables that render it, #} {# so the verdict codes and their colours cannot drift apart. #} {% macro badbot_cell(code, dash_class) %} {% if let Some(c) = code %} {% if c == "bad_address" %} bad address {% else if c == "bot_user_agent" %} bot user-agent {% else if c == "bad_address_bot_user_agent" %} bad address + bot user-agent {% else %} unknown {% endif %} {% else %} — {% endif %} {% endmacro badbot_cell %}
