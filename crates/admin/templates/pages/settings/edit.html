IP reputation

A client that trips a site's rate limit is answered 429. When this check is on, the gateway asks a reputation library about the client first: an address the library convicts, or a user agent that declares itself a bot, is answered 403 with the site's own error page instead. A crawler the known-bot validator confirmed is never escalated.

These settings live in the database, not in ngx.yml — the only credential they carry is a provider API key, and a key in the configuration file ends up in backups and in shell history.

The gateway asks the library for a second opinion about a client it has already decided to reject, so lenient is the right bar.
