# 配色更新说明 - 琥珀橙强调色

**更新日期**: 2026-06-08  
**版本**: 1.1.0

## 变更原因

基于用户反馈，原紫蓝色 (#6366F1) 强调色"太 AI 感"，不符合产品定位。

**目标用户群体**：
- 中小企业的运维/运营人员
- 懂业务、懂一点点技术
- 需要可靠、温暖、接地气的工具

**新配色选择**：琥珀橙 (#F59E0B)

---

## 配色对比

| 属性 | 旧版（紫蓝） | 新版（琥珀橙） |
|------|-------------|---------------|
| **色值** | #6366F1 | #F59E0B |
| **RGB** | rgb(99, 102, 241) | rgb(245, 158, 11) |

| **对比度** | 8.6:1 (AAA) | 3.9:1 (AA 大文字) |
| **联想** | 科技、未来、冷静 | 连接、畅通、温暖 |

---

## 为什么选择琥珀橙？

### 1. 符合产品定位

**Pangolin = 穿山甲 = 打通隧道**
- 🔶 橙色象征"挖掘隧道、建立连接"
- 🔶 温暖色调 = 可靠连接
- 🔶 穿山甲的鳞片本身就是暖黄褐色

### 2. 符合用户群体

**中小企业运维/运营**
- ✅ 温暖可靠，不是"大厂冷冰冰"的感觉
- ✅ 接地气，符合中小企业调性
- ✅ 易辨识，在运维场景（日志、监控）快速识别状态
- ✅ 减少疲劳，暖色调比冷色调更友好

### 3. 差异化品牌

- 技术工具很少用橙色（蓝色泛滥）
- 形成独特的品牌记忆
- 参考案例：Cloudflare（橙）、PostHog（橙）

## 色彩心理学

### 橙色的含义

**积极面**：
- 🔥 温暖、友好、平易近人
- 🔗 连接、沟通、畅通
- ⚡ 活力、创新、行动力
- 🎯 清晰、可见、易识别

**适用场景**：
- 网络/通信工具（象征"连通"）
- 运维/监控面板（易于快速识别状态）
- 中小企业产品（温暖亲和）

**避免的误区**：
- ❌ 不是"警告色"（我们的警告色是同色系，但语义不同）
- ❌ 不是"廉价感"（通过设计质感和深色模式平衡）

## 可访问性

### 对比度测试

```
✓ 黑色文字 (#000000) on 琥珀橙 (#F59E0B)
  对比度: 5.4:1 → AA 级（正常文字）

✓ 白色文字 (#FFFFFF) on 琥珀橙 (#F59E0B)
  对比度: 3.9:1 → AA 级（大文字 ≥18pt）

建议：
- 按钮文字使用白色或黑色（根据深浅色模式）
- 小文字（<14px）避免使用琥珀橙作为背景
- 琥珀橙适合图标、边框、大标题
```

## 深色模式适配

琥珀橙在深色模式下的表现：

```css
/* 浅色模式 */
background: #F59E0B;  /* 琥珀橙 500 */
color: #FFFFFF;

/* 深色模式 */
background: #F59E0B;  /* 保持相同，或略微调亮 */
color: #000000;       /* 黑色文字对比更好 */

/* 深色模式的柔和变体 */
background: #FCD34D;  /* 琥珀橙 300 - 更柔和 */
color: #78350F;       /* 深褐色文字 */
```

## 迁移指南

如果您在其他模板或组件中使用了旧的紫蓝色：

### 查找替换

```bash
# 查找使用紫蓝色的地方
grep -r "6366F1" crates/admin/templates/
grep -r "indigo" crates/admin/templates/
grep -r "accent-5" crates/admin/templates/

# 替换为琥珀橙
sed -i 's/#6366F1/#F59E0B/g' <文件>
sed -i 's/indigo/amber/g' <文件>
```

### CSS 类名

无需修改！所有组件仍使用 `accent-*` 类名：
- `.btn-accent` ✅ 自动使用新颜色
- `.badge-accent` ✅ 自动使用新颜色
- `.text-accent-500` ✅ 自动使用新颜色

只需重新构建 CSS：
```bash
npm run build
```
